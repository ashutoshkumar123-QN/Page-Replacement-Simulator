How the algorithms decide

FIFO (First-In First-Out)
Evicts the page that has been in memory the longest. Simple, but can evict a page that is still heavily used.
LRU (Least Recently Used)
Evicts the page that has gone unused for the longest time, assuming recent use predicts near-future use.
Optimal (Belady's MIN)
Evicts the page whose next use is farthest in the future. It needs knowledge of the future, so it is a theoretical benchmark that no real system can implement, and it gives the minimum possible number of faults.
